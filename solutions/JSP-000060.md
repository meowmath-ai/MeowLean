# JSP-000060 · Uniform uncovered density for a fixed ratio

For every real $K>1$, there are $\delta>0$ and $N_0$ such that, for every real $N\ge N_0$, any finite collection of residue classes with distinct moduli in $(N,KN]$ leaves a set of integers of two-sided natural density at least $\delta$.

This is Conjecture 2 in Filaseta, Ford, Konyagin, Pomerance, and Yu, *Sieving by Large Integers and Covering Systems of Congruences*, J. Amer. Math. Soc. **20** (2007), 495–517. Conjecture 2 is stated on p. 496 and follows from Theorem B on p. 497. [Published proof](https://math.dartmouth.edu/~carlp/PDF/covfinal.pdf#page=2)

The proof splits the common period into coprime parts at a prime cutoff and counts surviving residues using the Chinese remainder theorem. A lower bound on the sum of the product weights and an upper bound on the sum of the pairwise errors give a positive difference. The cutoff depends only on the ratio. A bound on the number of smooth moduli supplies a threshold valid for all larger scales.

The [Lean proof](../supplements/JSP-000060/JSP000060.lean) uses residue-system definitions and estimates from Boris Alexeev's lean-proofs archive. The upstream `Erdos27` module credits OpenAI Codex and GPT-5.6 Sol for its formalization. The replay script downloads the six source modules at the pinned commit, checks their hashes, and applies the Mathlib 4.36.0 compatibility patch. [Upstream formalization](https://github.com/plby/lean-proofs/blob/8822f7ddef30fadbd92e1c6ab4ed897af356af5e/src/latest/ErdosProblems/Erdos27.lean)

Run the following commands from the repository root with Git, Elan, and Python 3.9 or later installed. The script fetches sources with PowerShell on Windows and curl on other platforms.

```sh
lake exe cache get Mathlib
lake env python supplements/JSP-000060/check.py
```

The script checks the modules in sequence and prints the axiom dependencies of `JSP000060.uniform_nat_window` and `JSP000060.erdos27_fixed_ratio_uniform`. Both depend on `propext`, `Classical.choice`, and `Quot.sound`.
