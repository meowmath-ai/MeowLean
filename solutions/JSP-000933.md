# JSP-000933

[Erdős Problem 1123](https://www.erdosproblems.com/1123) asks whether the Boolean algebras of subsets of the natural numbers modulo the ideals of natural-density-zero sets and logarithmic-density-zero sets are isomorphic. The [Justin Sun Prize catalog](https://github.com/TheJustinSunPrize/awards/blob/main/problems/catalog-0901-1000.md#JSP-000933) records the question as independent of ZFC.

The Lean theorem [`erdos1123_densityQuotients_relative_independence`](../supplements/JSP-000933/src/JSP000933RelativeIndependence.lean) states that if ZFC is consistent, then ZFC with the isomorphism sentence and ZFC with its negation are both consistent.

The isomorphism sentence describes a total and surjective relation on subsets of the natural numbers that preserves and reflects the two quotient orders. For either ideal, the quotient order relates the classes of `A` and `B` exactly when `A \ B` belongs to the ideal. The relation therefore induces an order isomorphism of the quotients, which determines their Boolean algebra operations. The sentence expresses vanishing density using eventual integer bounds on prefix masses. The logarithmic mass uses harmonic weights. The harmonic and logarithmic denominators give the same null sets. [Set-language sentence](../supplements/JSP-000933/src/JSP000933SetSentence.lean) · [Equivalence of null ideals](../supplements/JSP-000933/src/JSP000933GroundLogBlocksEquivalence.lean)

The consistency proofs use Boolean-valued models. A coupling forcing produces the isomorphism, and a finite-support iteration produces the open-coloring principle used to derive non-isomorphism.

## Reproduction

The repository pins Lean and Mathlib 4.36.0. With Git, Elan, and Python 3.10 or newer installed, run these commands from the repository root.

```sh
lake exe cache get Mathlib
lake env python supplements/JSP-000933/check.py
```

The replay script checks the proof and prints the axiom dependencies of the consistency and independence theorems. The audit declarations are in [`AuditJSP000933.lean`](../supplements/JSP-000933/src/AuditJSP000933.lean).
